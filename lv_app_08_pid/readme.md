# ⚙️ PID 仿真控制系统

### 📖 项目简介

基于 LVGL 实现的交互式 PID 控制算法仿真器。该项目集成了一个简易的物理运动引擎来模拟物体运动，并允许用户通过 UI 界面实时调节 PID 参数，直观观察算法对系统的控制效果。

**核心功能：**

* **实时交互** ：支持通过滑动条调节 **$K_P$**、**$K_I$**、**$K_D$**、积分限幅及输出限幅。
* **物理仿真** ：内置运动模型，支持恒定干扰力模拟。
* **双模式操作** ：支持鼠标/触摸直接“推动小球”或“修改目标位置”。
* **可视化反馈** ：实时显示当前位置与预期位置的数值及物理图像。

### 🛠️ 移植使用

1. **拷贝文件** ：将以下文件拷贝到你的工程目录：

* 应用逻辑：`pid_app.c` / `pid_app.h`
* UI 界面：`pid_ui.c` / `pid_ui.h`
* 算法核心：`pid.c` / `pid.h`
* 物理引擎：`motion.c` / `motion.h`

1. **配置头文件** ：确保你的工程已包含 LVGL 库及相关字体文件（`font_conf.h`）。
2. **参数配置** ：你可以在 `pid_ui.h` 中修改 UI 样式及滑动条的量程：

```c
/* ================== UI 样式配置 ================== */
#define BALL_COLOR          0xf26552    ///< 小球颜色
#define BALL_SIZE           36          ///< 小球直径
#define COLOR_BG            0x222518    ///< 背景颜色

/* ================== PID 调参量程配置 ================== */
#define KP_MAX              5000        ///< KP 滑动条最大值 (对应 500.0)
#define KI_MAX              5000        ///< KI 滑动条最大值
#define KD_MAX              5000        ///< KD 滑动条最大值
#define OUT_LIM_DEF_VAL     5000        ///< 默认输出限幅初值
```

4. **调用** ：在主函数初始化 LVGL 后，调用应用入口函数：

```c
extern void pid_app_entry(void);

int main(void)
{
    lv_init();
    // ... 屏幕与输入设备初始化 ...

    // LVGL 字库初始化
    lv_font_init();
    // 启动 PID 仿真应用
    pid_app_entry();

    while(1) {
        lv_timer_handler();
        usleep(5000);
    }
}
```

### 🕹️ 操作说明

* **参数调节** ：拖动右侧滑动条修改参数，**点击滑动条右侧的数值标签**可快速清零该参数。
* **模式切换** ：
  * **推动小球** ：在仿真区左右拖动，手动给小球施加瞬时外力。
  * **修改目标** ：在仿真区左右拖动，直接改变 PID 的控制目标位置。
* **复位** ：点击“复位小球”可清除动能并回到原点；“复位目标”将目标位置归零。
